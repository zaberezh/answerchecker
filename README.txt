screen_qa для Windows
=====================

Скриншот -> распознавание текста -> вопрос к модели -> номер ответа голосом.
Горячая клавиша F9. Быстрый выход: три раза "=" за секунду.

В папке три файла:
  screen_qa_win.py   сама программа, больше ничего не нужно
  requirements.txt   список библиотек
  build_exe.ps1      сборка в один exe, если Python ставить не хочется


ВАРИАНТ А. Запуск с Python (проще, 5 минут)
-------------------------------------------

1. Установить Python и Tesseract. В PowerShell:

      winget install -e --id Python.Python.3.12
      winget install -e --id UB-Mannheim.TesseractOCR

   В установщике Tesseract отметьте нужные языки в разделе
   "Additional language data", английский идёт всегда.

2. Закрыть и открыть PowerShell заново, затем в папке с программой:

      py -3 -m pip install -r requirements.txt

3. Ключ API уже вшит в screen_qa_win.py, настраивать ничего не нужно.
   Сменить его можно прямо в файле, строка API_KEY в самом начале.

4. Запустить:

      py -3 screen_qa_win.py

   Программа повиснет и будет ждать F9.


ВАРИАНТ Б. Один exe, Python на целевом ПК не нужен
---------------------------------------------------

Python и Tesseract нужны только на машине, где вы собираете.
Готовый exe работает где угодно, он несёт Tesseract внутри.

1. Поставить Python и Tesseract как в пункте 1 варианта А.

2. В PowerShell из этой папки:

      powershell -ExecutionPolicy Bypass -File build_exe.ps1

   Нужны другие языки OCR:

      powershell -ExecutionPolicy Bypass -File build_exe.ps1 -Langs eng,rus,pol

   Без окна консоли:

      powershell -ExecutionPolicy Bypass -File build_exe.ps1 -NoConsole

3. Получится dist\screen_qa.exe, примерно 80-120 МБ.
   Копируйте его на любой компьютер с Windows.

4. Запустить screen_qa.exe двойным щелчком. Ключ уже внутри.


КАК ПОЛЬЗОВАТЬСЯ
----------------

  F9                  снять экран и получить ответ
  = = =  за секунду   выйти, работает из любого окна
  Esc                 выйти

Ответ произносится голосом: one, two, three, four или minus,
если модель не смогла определить вариант. Он же печатается в консоли.

Полезные ключи запуска:

  --region 600,300,1300,800   распознавать только часть экрана
  --monitor 2                 другой монитор
  --no-speech                 без голоса
  --timeout 45                если сеть медленная
  --hotkey "<ctrl>+<alt>+q"   другая клавиша
  --exit-key ""               отключить выход по "="
  --once                      один раз и выйти
  --test-speech               проверить только звук
  --list-models               показать доступные модели
  --help                      все ключи


ЕСЛИ НЕ РАБОТАЕТ
----------------

Не найден tesseract
  Укажите путь вручную:
    py -3 screen_qa_win.py --tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe"

Нет голоса
  Проверьте синтезатор речи Windows, в PowerShell:
    Add-Type -AssemblyName System.Speech
    (New-Object System.Speech.Synthesis.SpeechSynthesizer).Speak('one two three')

Текст распознаётся плохо
  Сузьте область через --region, в ней должен быть только вопрос с вариантами.
  Мелкий шрифт читается хуже, помогает увеличение масштаба страницы.

F9 не реагирует
  Проверьте, что клавишу не перехватила другая программа.
  Смените её: --hotkey "<ctrl>+<alt>+q"

Сменить ключ API
  Поправьте строку API_KEY в начале screen_qa_win.py и пересоберите exe.
  Разово перекрыть можно переменной окружения:
    $env:OPENAI_API_KEY = 'другой-ключ'
  Ключ лежит открытым текстом в файле и внутри exe.
  Не выкладывайте их в публичный доступ.


Использовать только там, где это разрешено: учёба, свои конспекты,
доступность. Не применять на экзаменах и тестах, где это запрещено правилами.
